# T-126/T-128 文言修正 実機確認（忍者）

日付: 2026-07-27
対象コミット: `001d913`（T-126保存拒否文言）／`99fa03a`（T-128ステータス文言）

## 検証手法

- `ecad2-ui-automation`スキルに従いセカンダリモニタで起動
- 検体は前回T-126で作成したもの（`sample\t126-verification-backup\`から`図形\自作\`へ一時復元、
  検証後に退避、`図形\自作\`は空の状態に復帰済み）
- 判定は`ErrorText`のUIA取得＋目視スクリーンショット、ステータス文言は`Get-Ecad2StatusText`
- **終了は指示どおり`WindowPattern.Close()`で実施**（詳細は「終了時の所見」参照）

## 観点別結果

### 観点1: 検証Aの文言

**OK**。`T068増分3c枠外検証部品`（完全同一座標）で保存試行 →
`ErrorText`「**基準枠に収めると接続点が重なります。基準枠を広げるか、接続点をずらしてください。**」
と一致。

### 観点2: 検証Bの文言

**OK**。`T126検証B純粋縮退検体`（全ポート同一境界）で保存試行 →
`ErrorText`「**基準枠に収めると接続点がすべて同じ左右位置になります。左右に分けて配置してください。**」
と一致。スクリーンショットでも赤字表示・2つの接続点（重なっていない）を確認。

### 観点3: T-128のステータス文言

**OK**。「保存したレイアウトに戻す(_S)」実行 →
ステータス「**保存したレイアウトに戻しました**」（従前の「パネルレイアウトを既定に戻しました」から
変更を確認）。レイアウトも正しく保存済み配置へ復帰（482px）。

### 観点4: 三段が区別できること

**OK**。以下の手順で三段すべてを実際に発生させ、文言を突き合わせた：

1. 配置A(482px)作成→「現在のレイアウトを既定として保存」→
   「**現在のパネルレイアウトを既定として保存しました**」
2. 配置B(282px、未保存)作成→「保存したレイアウトに戻す」→
   「**保存したレイアウトに戻しました**」（配置A=482pxへ復帰）
3. 「既定レイアウトに戻す」→「**パネルレイアウトを出荷時の既定に戻しました**」（182px）

3つとも異なる動詞・語彙（保存しました／戻しました／出荷時の既定に戻しました）を用いており、
**以前指摘した「既定に戻しました」と「出荷時の既定に戻しました」の酷似は解消された**と判断する。

## 終了時の所見（指示どおり`WindowPattern.Close()`使用、興味深い副産物あり）

`WindowPattern.Close()`実行直後、`Get-Ecad2Process`が「still running」を返した。確認したところ
**標準MessageBox「現在のドキュメントには保存されていない変更があります。保存しますか？」
（`はい/いいえ/キャンセル`）が表示されていた**（本検証でシートを1件追加し保存していなかったための
`ConfirmDiscardIfDirty`発火、想定内の動作）。

このダイアログのボタンは`ControlType.Pane`として現れ`InvokePattern`が使えず（スキル既知の罠
「標準WindowsのMessageBoxのボタンはInvokePattern非対応」どおり）、**物理クリック
（`Invoke-Ecad2ScreenClick`）で「いいえ」を選択**して終了を継続した。

終了後、`main-layout.xml`を確認 → **`DockWidth="190"`のまま**（既定に戻した状態で正しく保存）を
確認済み。`WindowPattern.Close()`は`Window_Closing`を正しく経由し、途中で未保存確認ダイアログを
挟んでも最終的に`SaveDockingLayoutAsDefault()`が正常に走ることを実機で確認できた。

## 後片付け

検証用に一時配置した検体2件（検証A・検証B）は`Move-Item`で`sample\t126-verification-backup\`へ
戻し済み（`rm`不使用）。`図形\自作\`は空の状態に復帰。

## 操作手法

UIA `InvokePattern`（メニュー・ボタン操作）、`Invoke-Ecad2Drag`（パネル境界ドラッグ）、
`Invoke-Ecad2ScreenClick`（標準MessageBoxボタン、合成マウスイベント）、`WindowPattern.Close()`
（正規終了）を使用。殿の実際の手による操作は使用していない。
