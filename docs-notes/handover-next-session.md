## 1. 次の家老が引き継ぐ設計上の要点

### T-155＝グループ枠は「二態」になった

- グリッド式（`GroupFrame.Visual*Mm` が全 null。作成直後・旧ファイル）と自由式（全設定。リサイズ後）。
- レンダラ（`DiagramRenderer.FrameRectMm`／`LadderCanvas.FrameRectMm`）は元より `VisualXMm ?? グリッド計算` の形。
- 自由式の枠は移動ドラッグ・矢印キー移動で `Visual*Mm` もセル差分ぶん追随（`ShiftFrameMm`）。
  行挿入・削除は `RowOps` が `VisualYMm`/`VisualHeightMm` を追随（`cellMm` 引数を追加、既定 `GridGeometry.DefaultCellMm`）。
- 自由式の枠の移動可否は下限（行・列 >= 0）のみ（`IsFrameMoveAllowed`。`Width`/`Height` が丸め近似ゆえ
  グリッド上限判定は使えぬ。自由線・接続点と同じ扱い）。
- ページ境界クランプは「グリッドの右下端まで」。主回路シートで枠をグリッド外へ広げる需要が出れば別途。
- `GridGeometry` へ `DefaultCellMm`／`FrameTopMm`／`FrameRowAt` を新設（`Cell*0.4` の重複を1つ解消）。

### T-156＝パーツエディタの作図スナップ

- `PartEditorCanvas.SnapEnabled`（public、既定 false＝自由）。ツールバーの「スナップ」トグルで切替。
- OFF なら `PartShapeGeometry.Snap(x, 0)` で素通し（`Snap` に「fractionCells <= 0 は素通し」ガードを追加、
  `GridLinesAt` と同型）。ON なら 1/4 刻み。
- 接続点は無改修＝`ClampPort` がトグルと無関係に常に整数セル格子へ丸める（電気的結線の基準。
  非整数だと `NetlistBuilder` が誤結線・誤断線・シミュ狂いを招く。Explore の調査 `a21a115a` で裏取り）。
- 回転の 15度スナップ（`SnapAngleDeg`）・見える4×4薄線グリッド（`FineGridStepCells`）は別系統ゆえ無改修。
