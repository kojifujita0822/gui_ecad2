## 4. 次の一手

### 4-1. 【最優先・本日新たに立った主題】接続方法の設計

**発端＝殿のご下問「組み込み図形は現在DRCで判定できているのでは？」**
**答え＝`docs/ecad2-t136-drc-vs-portkind-investigation-onmitsu.md`（隠密）。以下はその要旨にござる。**

#### 判明したこと（**すべて一次ソースで確定**）

1. **DRCは接続点を一つも見ておらぬ**——**診断コード10種はすべて`Component`か`Netlist`を入力とし、`PortDef`を直接見るものは0件**。
   **判定していないのではなく、判定しようがない位置にござる**：
   ```
   接続点(PortDef) → [NetlistBuilder] → Netlist → [DRC] → 診断
        ↑ 種類はここ                              ↑ DRCはここ
   ```
   **接続点は節点へ潰された後ゆえ、DRCが受け取る頃には「どのポートだったか」が失われておる**

2. **【核心】三相モータは「Componentにならぬのに、母線へは繋がる」**——`NetlistBuilder.cs:307`のコメントが**モータを名指し**
   （`// 記号のみ(三相モータ・非シミュ自作)は評価対象外`）。**されど「評価対象外」が効くのは最後の段階だけ**にござる：

   | 段階 | モータは |
   |---|---|
   | `:141` ポート0個の除外 | **通過**（3ポートゆえ） |
   | **`:160-161` 母線への直接union** | **参加**（`CreatesComponent`を見ぬ） |
   | `:179` 行索引 | **載る** |
   | **`:212-216` 横配線の結合** | **参加**（隣接要素と結線） |
   | `:307` Component生成 | **除外**（ここで初めて効く） |

   **`CheckLoadReachability`は`net.Components`を回すゆえ、モータは検査の対象にすらならぬ。**
   **モータが横配線で母線へ繋いだ結果、本来届かぬはずの負荷が届けば`DRC-LOAD-001/002`は出ぬ**
   ——**誤った接続が、DRCに「異常なし」と言わせる。**

3. **重複ではなく、上流と下流**——**母線へ繋ぐか否かを決めておるのは「位置」ただ一つ**（`leftBoundary==0`／`rightBoundary==columns`）。
   **部品の側に「この点は電源に繋ぐ／繋がぬ」と言う手立てが無い。**
   **種類が入れば`:160-161`が「位置」でなく「意味」で判定できる**——**DRCの重複ではなく、DRCの入力を正しくするもの。**

4. **【最重要の申し送り】種類を付けただけでは何も変わらぬ**——**増分4の`PortKind`は「見た目のみ」と`Element.cs`に明記されており、
   `NetlistBuilder`が`Kind`を見るようにして初めて効く**（**殿裁定2026-07-28(5)「接続方法は別途設計する」に相当**）

5. **欠けておるのは三つ**——(1)接続点が意図を持つこと（**増分4で入った、見た目のみ**）
   (2)**`NetlistBuilder`が意図を見ること（未着手＝本節の主題）**
   (3)**`CreatesComponent`の関門が全経路に効くこと（7経路中3つのみ）**
   ——**「非シミュレート」という宣言が既にありながら、それが配線を止めておらぬ。**
   **接続点の種類を入れても、`:160-161`が種類を見ねば同じ穴が残る**

#### 着手前に為すべきこと

- **【実測が要る・隠密が断じておらぬ】**「モータ経由で他の要素が母線へ繋がる」は**構造からの推論にて未実測**。

  本日、隠密は機序を確定させ忍者の実測4件を説明しDRCの構造を解いた——それは目の働きにござる）**
- **隠密（続）**＝**「某の誤り六つのうち五つは他役が持ち込んだもの。数えられたのは数える力があったゆえではなく、
  持ち込まれる仕組みが在ったゆえ——書き残す作法と、他役が拾う体制と、その両方が揃うて初めて数えられ申した。
  片方だけでは、誤りは誤りのまま残る」**
- **侍**＝**検出力ゼロと分かったテストを消さず「安全網に過ぎぬ」と限界を明記して残した。**
  **隠密の評＝「測れぬと分かったものを消せば、次の者は『測られておる』と思い込む」**
- **忍者**＝**測っておらぬものを「測っておらぬ」と区切り続けた**（区切り線3段の全網羅／画像パスの未検分／カテゴリの再測定せず）。
