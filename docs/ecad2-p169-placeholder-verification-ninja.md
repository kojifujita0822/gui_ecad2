## 2. 経路を先に列挙して尽くした（五経路）

| # | 経路 | 症状 |
|---|---|---|
| 1 | 編集(E) → 削除(D) | **出る**（パネル消失・プレースホルダ出ず） |

## 3. 機序を実測で裏づけた

**削除直後は空白であるが、別セルを叩くと即座にプレースホルダが出る。**

```
削除直後              : panel=absent | placeholder=absent   ← 症状
別セルをクリック後    : panel=absent | placeholder=SHOWN     ← 正常へ戻る
```

**`SelectedCell` の setter が走れば通知が飛ぶゆえ**にござる。
**経路5（シート切替）が正常なのも同じ理**——切替で `SelectedCell` が「未選択」へ変わり setter が走る。

**すなわち症状の有無は「`SelectedCell` の setter を経由するか否か」で決まっており、
隠密の静的読解**（`HasNoPropertySelection` の通知が `SelectedCell` の setter にしか無い。
`MainWindowViewModel.cs:512` のみ。`DeleteSelectedElement` は `SelectedCell` を書き換えぬゆえ通知されぬ）
**と一致する。**

**通知の所在**（忍者が観点を組むために確認した範囲）——
`HasSelectedElement` の通知は4箇所（`:498`／`:2541`／`:2678`／`:3632`）、
**うち `HasNoPropertySelection` を伴うのは `:498`→`:512` のみ。**

## 4. 自ら区切った射程（未測・未確定を明記する）

### 4-1. 未測が一経路ある

**`NotifySelectedElementChanged`（`MainWindowViewModel.cs:2678`＝行削除等で明示的に呼ぶ経路）は
測っておらぬ。** 右クリックメニューが**「削除／機器名変更/コメント編集」の三つのみ**で、
**行削除の導線に辿り着けなんだゆえ。**

**ゆえに正しくは**——**「五経路のうち三つで症状、一つは経路不成立、一つは正常。残る一経路は未測」。**
**次に測る者は、行の挿入・削除メニュー**（`ecad2-ui-automation`スキル記載＝T-055増分3で
行番号側に実装された ContextMenu）**から入られたい。**

### 4-2. `Ctrl+X` が不発であった理由は切り分けておらぬ

**要素が消えなんだ**（機器表の行数が変わらず、パネルも残った）。
**`Ctrl+Z` と同じくキャンバスフォーカスのガードがある恐れもあるが、確かめておらぬ。**
**ゆえに「切り取りは効かぬ」とは断じぬ**——**本日、忍者自身が `Ctrl+Z` のフォーカス要件で
足を掬われており**（増分5の再確認、`ecad2-ui-automation`スキル`:786-787`に既載の罠）、
**同じ形を疑いながら未確認ゆえ留保する。**
