## 0. 総括

**最も肝要な発見は「横は列境界基準、縦は行中心基準」という座標系の非対称にござる。**
`GridGeometry.cs:18-20`——

```
X(boundary) = Margin + boundary * Cell        ← 境界そのもの
YRow(row)   = Margin + (row + 0.5) * Cell     ← 行の「中心」（半セルずれ）
```

**ピッチはどちらも Cell（既定9.0mm）で同一。基準だけが半セル違う。**
**これが「横は`CellWidth`で表せるのに、縦が器を持てぬ」ことの構造的な理由にござる。**

そして——**`ElementCatalog.DefaultCellWidth` は呼び出し元がゼロ**であった
（下記2-2）。**`ElementKind`経路の幅カタログは、既に死んでおる。**
**案B（`ElementKind`経路の新設）は「眠っている器を起こす」作業を含む**と心得られたい。

## 1.【DoD 3】描画は実際に縦2セル分に及ぶか——**及ぶ。されど形が違う**

### 1-1. 一次ソースによる確定

| 事実 | 出典 |
|---|---|
| 描画の原点は**アンカー行の中心** | `DiagramRenderer.cs:1033`＝`r.PushTransform(X(lb), YRow(e.Pos.Row))` |
| その裏付け（1セル背景が行中心から上下へ） | 同`:1036`＝`FillRectangle(new(0, -Cell/2, Cell, Cell), bg)` |
| `YRow`が行の中心を返す | `GridGeometry.cs:20`＝`MarginMm + (row + 0.5) * CellMm`（クラスコメント`:5`にも明記） |
| **縦向き(V)**＝流れ軸 f∈[-1,+1]、Y座標＝`f*k`（k＝1セル） | `SymbolGlyphs.cs:256`（`P(f,g)`）／`:292`（`fMin=-1, fMax=1`） |
| **横向き(H)**＝極の並び軸 c∈{-1,0,+1}、Y座標＝`(c+g)*k` | `SymbolGlyphs.cs:247`（`PoleAcrossH`）／`:256` |
| 横向きのラベルを1.05セル上へ置く（背が高いため） | `DiagramRenderer.cs:1043`のコメント＋`:1055` |

### 1-2. 帰結＝**「下へ2行」ではなく「上下1セルずつ」**

行の高さを1セルとすると、描画のY範囲は**行中心 ±1セル**。すなわち——

```
行 R-1 ┃          ← 下半分が侵される
行 R   ┃■■■■■  ← アンカー行（全体）
行 R+1 ┃          ← 上半分が侵される
```

**計3行にまたがり、上下は半分ずつ。** **`ElementInstance`に高さ2を足して
「`Pos.Row` 〜 `Pos.Row+1`」と解釈すると、描画とずれる。**

### 1-3. 横方向は正しく整合しておる（対照）

| 向き | 極の座標 | 範囲 | `CellWidth=2`との整合 |
|---|---|---|---|
| V | X＝`(c+g)*k`、c∈{0,1,2} | 左境界から**0〜2セル** | **合う** |
| H | X＝`f*k`、f∈[0,2] | 同上 | **合う** |

**横は左境界基準で0起点ゆえ`CellWidth`にそのまま乗る。縦は中心基準ゆえ乗らぬ。**

## 5.【殿ご下命】接続点は縦配線のセルピッチに合うか

### 5-1. 数値で示す（既定 Cell=9.0mm、Margin=15.0mm）

| 対象 | 式／刻み | ピッチ | 基準 |
|---|---|---|---|
| 列境界 | `X(b) = 15.0 + b*9.0` | **9.0mm** | **境界そのもの** |
| 行中心 | `YRow(r) = 15.0 + (r+0.5)*9.0` | **9.0mm** | **中心（半セル4.5mmずれ）** |
| **ポートのノード座標** | `(Pos.Row + RowOffset, Pos.Column + BoundaryOffset)` | **行・列とも整数** | `NetlistBuilder.cs:145` |
| **縦コネクタ** | 行＝`TopRow`/`BottomRow`（**整数**）／列＝`Column`（**0.5刻みのdouble**） | 列のみ**4.5mm** | `NetlistBuilder.cs:266-267`／`GridGeometry.cs:32` |

### 5-2. 突き合わせ

| 軸 | 判定 |
|---|---|
| **行方向** | ポートも縦コネクタも整数・1行ピッチ＝**完全に一致する** |
| **列方向** | ポートは整数、**縦コネクタは0.5刻み＝2倍細かい** |

**`NetlistBuilder.cs:284`に明記されておる**——
`bool integral = vc.Column == Math.Floor(vc.Column);   // 0.5 位置は中間行ノードと厳密一致しない`

**すなわち「セル中央（X.5）に置いた縦コネクタは、部品の接続点と厳密には合わぬ」——
これは既知として設計に織り込まれておる。**

### 5-3. 3極記号の極はグリッドに載る（幾何）

| 向き | 極の位置 | 判定 |
|---|---|---|
| V | 列境界 `lb`／`lb+1`／`lb+2` | **列境界ピッチと完全一致** |
| H | 行 `R-1`／`R`／`R+1` の**中心線上** | **行ピッチと完全一致** |

**幾何的には、縦横いずれの向きでもグリッドに正しく載る。**

### 5-4.【DoD 8】電気的には繋がらぬ——**ただし殿のご教示により、この論点は主回路シートでは落ちる**

`ElementCatalog.Ports`（`:31-32`）が3極記号に**空配列**を返す
→ `NetlistBuilder.cs:141`＝`if (ports.Count == 0) continue;`＝**ノードが1つも作られぬ**
→ `:179`＝`if (!hasPorts[i]) continue;`＝**横配線・母線接続からも除外**

**3極記号はネットリスト上に一切現れぬ。** 設計どおり（自由線`FreeLine`で結線する前提、
`ElementCatalog.cs:30`のコメント）にござるが、**`FreeLine`はmm実座標＝グリッド非依存**
（`Element.cs:74-86`）。

> **【殿のご教示 2026-07-28】「主回路シート上ではDRC・接続判定は行っていない。判定は無視していい」**
>
> **これにより本節後半の論点は、主回路シートに関する限り落ちる。**
> ポート0個ゆえネットリストに現れぬことも、`NetlistBuilder`から除外されることも、
> **主回路シートでは問われぬ。**
> **残る的は幾何的な整合のみ**——すなわち5-1〜5-3の数値突合が本体にござる。

**幾何についての結論＝合う。** 3極記号の極は縦横いずれの向きでもグリッドピッチに正しく載る
（5-3）。**幾何上の問題は無い。**

### 5-5.【切り分け】組み込みパーツは**制御回路シートにも置ける**——ゆえに直交の実害は落ちきらぬ

| **描画** | 端子円が`(0.30,-1) (0.30,0) (0.30,+1)`＝**同一X・Y違い＝縦並び** | 同`:251-263` |
| **コメント** | 「大円＋**左に縦3端子**(⊘)＋リード」 | 同`:240` |

**見た目の端子は縦に並ぶのに、ネットリスト上のノードは横に並ぶ。完全に直交しておる。**
**縦配線を見た目の端子へ繋いでも、ノードはそこに無い。**

**由来を追った**——T-071設計書（`docs/archive/ecad2-t071-part-addition-design-onmitsu2.md:65-72`）は
**「`ElementCatalog.Ports(Motor,...)`と同型の専用3ポート定義が必要」と述べるのみで、
ポートの並びが縦か横かを論じておらぬ**。
**描画は`SymbolGlyphs.Motor`由来、ポートは`ElementCatalog.Ports`由来——
それぞれ別々に移植され、両者が突き合わされなんだ**と見受ける。

**【バグか意図かは不明と明示する】**——`Motor`は`Role = PartRole.NonSimulated`
（`BasicPartTemplates.cs:249`）ゆえ`CreatesComponent`はfalseになるが、
**`NetlistBuilder.cs:144-145`のノード生成は`CreatesComponent`と無関係に走る**。
ゆえに**ノードは横並びで実際に作られる**。**実害が顕在化しにくいのは、三相モータを主回路で使い、
主回路は自由線で結線する運用ゆえ**と推測する。

**なお家老の問い「御下命は自作パーツ全般か3極記号か」への答え＝両方に論点があるが質が違う**——
