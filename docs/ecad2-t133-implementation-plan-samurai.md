## 2. 一次ソースで確かめた事実——**規模の根拠**

### 2-1. 【留保の解消】3極記号の描画は **V/Hとも「幅2セル × 高さ2セル」**

`SymbolGlyphs.cs:288-350` を全文直読した。`k = width / 2.0` で `CellWidth=2` ゆえ **1単位＝1セル**。

| 向き | 極の並び（across） | 流れ（f） | 描画の及ぶ範囲 |
|---|---|---|---|
| **縦 V** | x = 0 / 1 / 2（列境界） | y ∈ [-1, +1] | 幅2セル・**行中心から上下1セルずつ** |
| **横 H** | y = -1 / 0 / +1（行中心） | x ∈ [0, 2] | 幅2セル・**行中心から上下1セルずつ** |

**すなわち「2×2セル」という公称は正しい。ただし基準は「行中心」であり「上端」ではない。**
先の見立てで「描画が縦2セル分に及ぶかも未確認」と留保した点が、これで解けた。

**【新発見】公称の 2×2 を超える描画が2つある**——

1. **ELBのテストボタン**（`:309`）＝`poles[2] + 0.55` の位置に置く。
   **V向きなら x=2.55（右へ0.55セルはみ出す）／H向きなら y=+1.55（下へ0.55セルはみ出す）**
2. **Breaker3P の弧**（`:302`、頂点 g = -ha = -0.42）＝across方向へ -0.42。
   **V向きなら最左極（x=0）の弧が x=-0.42 まで及ぶ（左へはみ出す）／H向きなら最上極の弧が y=-1.42**

→ **占有判定を「幅2×高さ2」で作っても、描画は最大0.55セルはみ出す。**
**占有と描画の完全一致は原理的に取れぬ**——これは割り切りとして受け入れる（§4-1 に論点として記す）。

### 2-2. モータの現況——**描画は高さ2セル。ポートは横並び**

`SymbolGlyphs.cs:219-238`（`k = width / 3.0`、`CellWidth=3` ゆえ1単位＝1セル）
- 端子は **y ∈ {-1, 0, +1}＝縦に3つ**、x=0.30。本体大円は中心 x=2.05・半径0.92
- **y範囲は -1〜+1＝高さ2セル**（3極記号と同じく行中心基準で上下1セルずつ）
- **x範囲は 0〜2.97＝幅3セルに収まる**

ポート定義は `ElementCatalog.cs:24-29` ＝ `PortDef("U",0,0)("V",0,1)("W",0,2)`
＝**RowOffset は全て0（同一行）・BoundaryOffset 0/1/2＝横並び**。**描画と直交する**（隠密の発見）。

**【重要】`SymbolGlyphs.Draw` は Motor へ `orient` を渡しておらぬ**（`:43`＝`Motor(r, s, width, cell)`）。
3極記号のみが `horiz` を受け取る（`:45-47`）。**増分8では switch の当該1行も改める要がある。**

## 4. 殿の裁可を要する論点——**4件**

### 4-1. 【最重要】**占有行の基準をどこに置くか**

**3極記号の描画は「行中心から上下1セル」（§2-1）だが、既存の唯一の先例
`IsFrameWithinGridBounds` は「上端基準」（§2-3）。この2つは食い違う。**

| 案 | 占有する行 | 長所 | 短所 |
|---|---|---|---|
| **(H-2) 中心基準・3行** | r-1, r, r+1 | **描画が及ぶ全行を覆う**。描画を変えずに済む | 公称「2×2」と合わぬ（実質3行）。**上端の行が0のとき配置できぬ**（グリッド上端に置けなくなる） |
| **(H-3) 上端基準・2行＋描画を半セル下へ** | r, r+1 | **公称2×2と一致**。`GroupFrame` と基準が揃う | **見た目が半セル下へずれる**。既存の3極記号（まだ配置手段が無いゆえ実害は無い） |
| **(H-4) 中心基準・2行（下寄せ）** | r, r+1 | 公称と一致し描画も不変 | **上半分（r-1 の下半分）が占有外に残る**——重ねて置けてしまう穴が残る |

**侍の推奨＝(H-2)。** 理由は「**描画が及ぶ範囲を覆う**」という占有判定の本義に最も忠実ゆえ。
**短所（上端行に置けぬ）は、3極記号が主回路シート専用であることを踏まえれば実害が小さい**と見る。

**ただしこれは使用感に関わる**（置ける場所が変わる）ゆえ、**侍の一存では決めぬ**。

**【併せて申し上げる】いずれの案でも、描画と占有の完全一致は取れぬ**——§2-1 の新発見のとおり、
**ELBのテストボタンが0.55セル、Breaker3Pの弧が0.42セル、公称の外へ出る**。
**「はみ出しは許容し、公称の矩形で占有を判ずる」という割り切りを前提とする。**
