## 2. メニュー経由と部品リスト経由の同一性（独立検証の主眼）

計画書の独立検証欄＝「メニューから置いた要素が部品リストから置いたものと同一になるか」。
**目視ではなく機械判定とする**（`ninja.md`の既定作法、スクショ罠の教訓）。

**手順**：同一シートの異なるセルへ、メニュー経由・部品リスト経由それぞれで同じ部品を1つずつ配置し保存。
`.gcaddoc`を直読し、両要素のJSON（`PartId`／`Kind`／`WidthCells`／`HeightCells`／`Ports`）を比較する。

| # | 確認項目 | 期待 |
|---|---|---|
| 2-1 | `PartId`が両経路で同一文字列か | 一致 |
| 2-2 | `WidthCells`／`HeightCells`が両経路で同一か | 一致 |
| 2-3 | 見た目（記号形状）が両経路で同一か | 保存JSONの`PartId`一致から論理的に導かれる想定だが、**念のためPDF出力または
  キャンバス上の並び置きで目視も併用**（機械判定を主、目視は補助） |
