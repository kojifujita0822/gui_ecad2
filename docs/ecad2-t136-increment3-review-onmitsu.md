## 所見1【要指摘】`ring > fill` は「種類色を隠さぬ」の十分条件ではござらぬ

### 測っておるものと、守るべきもの

**守るべきもの**（某の案A・侍のコメント・家老の問い、いずれも同じ）＝
**「リングが塗りを覆えば、増分4で入る種類色が隠れる」ゆえ、覆わぬこと。**

**測っておるもの**（`選択リングは塗り円より大きい`）＝**`ring > fill`、すなわち中心線どうしの大小。**

**リングは`DrawCircle`＝輪郭線**にて、**線幅`PortRingStrokeMm = 0.15`を持ち申す。**
**線は半径`ring`を中心に幅0.15で描かれるゆえ、内縁は`ring - 0.075`にござる。**

**塗りを覆う条件**＝`ring - 0.075 < fill`
→ `0.20·cellMm - 0.075 < 0.14·cellMm`
→ `0.06·cellMm < 0.075`
→ **`cellMm < 1.25`**

**すなわち`ring > fill`が成り立っておっても、`cellMm`が1.25mmを下回ればリングは塗りへ食い込み申す。**

### 実害の有無——**現時点では無い。されど測れてもおらぬ**

| `cellMm` | 中心線の大小 | 内縁が塗りを覆うか |
|---:|---|---|
| 9.0（既定） | `1.80 > 1.26` ✓ | 内縁1.725 > 1.26 ＝**覆わぬ** |
| 2.5（テストの縮小側） | `0.50 > 0.35` ✓ | 内縁0.425 > 0.35 ＝**覆わぬ** |
| **1.25** | `0.25 > 0.175` ✓ | 内縁0.175 = 0.175 ＝**境界** |
| **1.0** | `0.20 > 0.14` ✓ | 内縁0.125 **< 0.14 ＝覆う** |

**テストの3ケース（9.0・2.5・20.0）はいずれも安全側**にて、**現に壊れてはおり申さぬ。**
**されど「大小関係を測っておけば増分4の種類色は守られる」とは言えませぬ**——
**線幅が勘定に入っておらぬゆえ。**

### 家老の問いへの答

> **「今測れておるものが、次の増分で守るべきものと合うておるか」**

**合うており申さぬ。** **中心線の順序は、被覆の有無とは別の量にござる。**
**両者が一致するのは`cellMm`が十分大きい時のみ**にて、**その前提はどこにも書かれておりませぬ。**

### 対処案（いずれも安い。某は(a)を推す）

- **(a) 測る量を、守るべきものへ合わせる**——`Assert.True(ring - PortRingStrokeMm / 2 > fill)`。
  **`cellMm`が小さい側（1.0等）を1ケース足せば、現に鳴る**
- **(b) 前提を明記する**——「`cellMm ≧ 1.25`でのみ被覆せぬ」と関数のコメントへ書き、
  **その下限が実際に守られておるか（パーツエディタのズーム下限）を別途確かめる**
- **(c) 据え置き**——実害が出るのは`cellMm < 1.25`のみゆえ

**【某が自ら射程を区切る】パーツエディタのズームが`cellMm`をどこまで下げうるかは、某は確かめており申さぬ。**
**下限が1.25mmを下回らぬなら、本件は理屈の上の穴に留まり申す。**
**確かめるには`PartEditorCanvas`のズーム処理を追う要があり、1周目軽量の枠を越えると判じて留め置き申した。**
**要否のご判断を仰ぐ。**

## 所見3【経過観察】大小テスト3件は、比例テスト2件と検出力が重なる

`接続点の半径はセル寸法に比例する`は**期待値を直に測る**（`9.0→1.26/1.80`、`2.5→0.35/0.50`）。
**率が固定されておるゆえ、`ring > fill`は数学的にそこから従い申す。**

**侍は「値の一致だけを見ると、両方を同じ率にする改変を見逃す」と述べており申すが、
比例テストは期待値を直に測るゆえ、同値化すれば必ず鳴り申す**——**現に改変Aは比例2ケースも鳴らしており申す。**

**されど害は無く、除く要も無い**と判ずる。**`ring > fill`という不変条件を明示する値打ち**があり、
**増分4で率を触る者が「何を壊してはならぬか」を読み取れる形**になっておるゆえ。
**記録に留め申す。**
