## 2. 観点2＝枷が効くか（**UIが無くとも測れ申した**）

### 測り方＝永続化ファイルへ直接書く

**`PartDefinition.SheetAffinity`の永続化は`JsonSerializer`による自動反映**であり、
`PartLibrarySerializer`は手書きのマッピングを持たぬ（侍のdocコメント）。
**ゆえに`.gcadpart`へ`"sheetAffinity"`を書き足せば読まれる。**
既存ファイルの`"role": "contactNO"`から**enumはcamelCaseの文字列**と読み取り、3値の検体を作った。

### 対照表（6通り）

**素朴なベースライン（`any`）を両シートに混ぜてある**——枷付き2件だけを並べると、
「置けなんだ」が枷ゆえか別の理由かを分けられぬため。

| 検体 | `sheetAffinity` | **制御回路シート** | **主回路シート** |
|---|---|---|---|
| `T136AFFANY` | `any` | **置けた**（Y1） | **置けた**（M3） |
| `T136AFFCTRL` | `controlOnly` | **置けた**（Y2） | **置けぬ** |
| `T136AFFMAIN` | `mainCircuitOnly` | **置けぬ** | **置けた**（M1） |

**6通りすべて期待どおり。** 機器表の行数で機械的に判じた（置けた＝+1、置けぬ＝据え置き）。

**シート種別の同定も併せて固定した**——主回路シートでは`自由線(横線)記入 (F9)`・
`自由線(縦線)記入 (Shift+F9)`・`接続点記入 (F10)`が**有効**、制御回路シートでは**無効**。
**「主回路シートのつもりが制御シートだった」という取り違えが起きぬよう、毎回この3つで確かめてある。**

### 拒否の見え方＝**サイレント**（殿裁定どおり）

**メッセージは一切出ぬ。** **配置バーは開き、名前を入れてEnterを押す操作も通る**——
**だが要素は生まれぬ。** 機器表も増えず、キャンバスにも何も現れぬ。
**使い手から見れば「確定したのに何も起きぬ」**という形にござる。

## 3. 【自戒】「配置バーが開いた」を「置けた」と判じかけた

**当初、拙者は「配置バーが開いたか」で成否を判ずるつもりであった。これは誤りにござる。**

**`ValidatePlacement`は確定の段で走る**（`MainWindowViewModel`の配置実行部）。
**配置バーが開くのはそれより前**ゆえ、**枷で拒まれる部品でも配置バーは開き、確定操作も通る。**

**この指標のまま報じておれば「枷が効いておらぬ」と誤報していた**——
**機器表と絵で実体を見て、初めて正しく判った。**

**教訓＝入口が開いたことは、通れたことではない。** 配置系の検証では**必ず結果側の指標**
（機器表の行数・キャンバスの絵・保存ファイルの中身）で判ずること。

### 併せて＝`IsOffscreen=True`の項目はクリックが空振りする（**新しい罠**）

**`T133INC1H3`が2度続けて「置けなんだ」と出て、危うく回帰と報ずるところであった。**
真因は**リスト項目の`IsOffscreen`が`True`**——**`FindAll`で拾え、`BoundingRectangle`も返るが、
実際には可視範囲の外**にて、その座標を叩いても何も起きぬ。

**切り分けの手順**（`ninja.md`「要素を1つずつ剥がして測れ」に従った）：
1. **同じセルに別の部品（`T136AFFANY`）を置いた** → **置けた**＝セルの問題ではない
2. **同じ部品を別のシートで試した** → **同じく置けぬ**＝シート種別の問題でもない
3. **リスト項目の属性を採った** → **`IsOffscreen=True`** ＝**手法の欠陥と判明**

**対処**＝`ScrollItemPattern.ScrollIntoView()`で送り、**送った後で矩形を取り直してから**クリックする。
これで置けた。**スキル6.1節「リストの初期表示は全件ではない」の変種**にて、
**あちらは「拾えぬ」、こちらは「拾えるが叩けぬ」**——**後者の方が危うい**（見つかった気になる）。

## 4. 観点3＝枷は移動にも効くか（**未測定**）

**枷に反する要素は配置の段で拒まれるゆえ、そもそも存在せぬ**——
**ゆえに移動を試すには、「置いた後で定義を書き換える」道しかない。**

**測り方（手順は立っており申す）**
1. 図面を保存する（主回路シートに`T136AFFANY`＝M3を置いた状態）
2. アプリを終了する
3. `T136AFFANY.gcadpart` を `"controlOnly"` へ書き換える
   → **主回路シートに制御専用の要素が在る＝枷に反する状態**ができる
4. 起動して図面を開き、M3 を矢印キー／ドラッグで動かす → 拒まれるか
5. 対照＝制御シートの Y1（同じ部品）は動くか

**【諮るべき点】この手順は「名前を付けて保存」を挟む。**
**保存を挟むと未保存でなくなり、終了時に`SaveDockingLayoutAsDefault`が走って
殿の`main-layout.xml`が上書きされる**（スキル既載・2026-07-28に実際に起きた）。
**退避と復元の手立ては取ってあるが、殿の設定へ触れる操作ゆえ、家老の判断を仰ぐ。**
