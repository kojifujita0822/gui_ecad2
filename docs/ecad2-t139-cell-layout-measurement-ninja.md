# ecad2 のセル配置 実測（忍者、2026-07-31）

> 家老采配＝殿のご指摘**「gui-ecadの基本的なセル配置とECAD2のセル配置が違っている。原本はセルの線上に
> パーツを配置する形であった」**を承けての実測。**ecad2の実機で「要素が行に対してどこに描かれるか」を
> 画素で採る。**
>
> **【断り】本書は採った数値のみを述べる。** 原本との一致・不一致は**述べぬ**——
> **家老より「先入観を持たぬよう、あえて『一致しておるはず』とは申さぬ」との申し送りを受けており、
> 忍者は画面の側から数値を出す役目にござる。** 隠密がコードの側から別途調べており、**Wチェック**となる。

**操作手法**：UI Automation（`InvokePattern`）／`Invoke-Ecad2CanvasClick`（Win32合成マウスイベント）／
`Send-Ecad2Keys`／`PrintWindow`撮影＋画素走査。**殿ご自身の手による操作は含まぬ。**

**構図**＝制御回路シート1枚に**a接点`X1`を1つ（行2/列3）**配置。母線・行番号・接点・そこから
右へ伸びる配線が1枚に収まる形（殿の御画像と同じ構図）。**座標はすべてウィンドウ相対**
（ウィンドウ`(1960,40)` 1400x800、ズーム100%、スクロール初期位置、左パネル幅190）。

## 1. 縦方向（行）＝**三者が同一のyに乗る**

```
横グリッド線   y=288
水平配線       y=288   ← 一致
要素の中心     y=288   ← 一致（選択枠 270〜306 の中点）
行番号の中心   y≈288.5 ← ほぼ一致（差0.5px）
```

**すなわち、要素は行のグリッド線の「上」に、中心を合わせて描かれておる。**
**配線もその同じ線の上を通る。**

**裏づけ**＝要素の無い帯（x=600〜700）で行を走査したところ、
**y=254・322・356…には薄い線（238）が出るが、y=288にだけ濃い線（30）が出る**。
**254+34=288** ゆえ**y=288もグリッド線の位置**にて、**そこへ濃い配線が重なって描かれておる**と読める
（薄い線が濃い線に覆われて見えぬ形）。

**要素の縦の広がり**＝選択枠 y=270〜306＝**36px**（1セル34pxよりやや大きい）。
**中心288から上下へ±18px。**

---

## 2. 横方向（列）＝**要素は線と線の「間」に入る**

```
縦グリッド線   x=399.5 と x=433.5（間隔34px）
要素の選択枠   x=398 〜 434        ← 2本の線の間をちょうど埋める
```

**縦方向とは異なり、要素は線の上ではなく、線と線の間に置かれておる。**

**すなわち ecad2 は、行は「線の上」・列は「線の間」という非対称な置き方**にござる
（**この非対称そのものが、殿のご指摘に関わる点かと存ずるが、判ずるのは忍者の役目に非ず**）。

---

## 3. 母線とグリッド線の関係

```
左母線         x=280.5
最初の縦グリッド線 x=297
差             16.5px ≒ 半セル（17px）
```

**母線はグリッド線の位置に無く、半セル分ずれた所に立っておる。**
右母線 x=994.5 と最後の縦グリッド線 x=978 の差も **16.5px** で同じ。

**母線間の距離**＝994.5 − 280.5 ＝ **714px ＝ 21セル分**（714 ÷ 34 = 21.0）。
