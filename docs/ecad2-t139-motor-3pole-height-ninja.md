# 三相モータ・3極記号の描画高さ 実測（忍者、2026-07-31）

> 家老采配＝侍の留保「三相モータ・3極記号の描画が、現在どちらを前提にしておるか」を埋める。
> `ElementCatalog.DefaultCellHeight`は**この2種を高さ2**と宣言。
> **殿裁定＝占有行は「奇数は`h`行、偶数は`h+1`行」ゆえ、高さ2なら3行。**

**操作手法**：UI Automation／`Invoke-Ecad2CanvasClick`（Win32合成マウスイベント）／`Send-Ecad2Keys`／
`PrintWindow`撮影＋画素走査。**殿ご自身の手による操作は含まぬ。**
**主回路シート1枚**に配置。座標は窓相対（ウィンドウ1400x800、ズーム100%）。

## 0. 結論

**三相モータ＝描画は3行に及ぶが、設定も占有も1行。三者が食い違っており申す。**

| 項目 | 値 | 出所 |
|---|---|---|
| `モータ.gcadpart` の `heightCells` | **1** | ファイル直読 |
| `ElementCatalog.DefaultCellHeight(Motor)` | **2** | コード（`ElementCatalog.cs:26`） |
| 図形の y 範囲（定義） | **-1.18 〜 +1.18 ＝ 2.36セル** | ファイル直読（13プリミティブ） |
| **実機の描画範囲** | **y=316〜396 ＝ 80px ＝ 2.35セル分** | **画素実測** |
| **描画が及ぶ行** | **行3・行4・行5 の3行**（中心は行4＝y356） | **画素実測** |
| **占有判定が押さえる行** | **1行のみ** | **実測（下記）** |

**3極記号（ブレーカ・電磁接触器主接点・サーマル2極）は配置導線が無く、測れ申さぬ**（§3）。

---

## 1. 描画が及ぶ範囲（DoD 1）

**行4/列3 へ`モータ`を配置**（機器名`MT1`）。要素の無い列を避け x=390〜500 で行走査。

```
y=316 から描画が始まり、y=396 で終わる（間に濃い線が断続）
行の中心線＝行3:y322 ／ 行4:y356 ／ 行5:y390
```

**描画は行3の中心より上（316）から、行5の中心より下（396）まで及ぶ。**
**80px ÷ 34px＝2.35セル分**にて、**定義の`-1.18〜+1.18`＝2.36セルと一致**（差0.01）。

---

## 2. 占有判定との突合（DoD 2）

**モータの隣接行へ a接点を置けるかで測った。**

| 置いた先 | 結果 | 機器表 |
|---|---|---|
| **行3/列3**（モータの描画が及ぶ行） | **置けた** | 1→2件 |
| **行5/列3**（同上） | **置けた** | 2→3件 |

**すなわち占有判定は1行しか押さえておらぬ。**
**描画は3行に及ぶのに、他の要素がその上へ重ねて置ける状態**にござる。

---

## 3. 殿裁定との突合（DoD 3）と、測れなんだもの

**殿裁定＝偶数は`h+1`行、高さ2なら3行。**

- **描画（3行）は裁定と噛み合う。**
- **だが定義（`heightCells=1`）と占有（1行）は噛み合わぬ。**
- **`DefaultCellHeight(Motor)=2`はKind経路の値**にて、**実機で置いた`モータ`はPartId経路**
  （`モータ.gcadpart`）ゆえ、**そもそも参照されておらぬ**と見える
  （**コード上の注記＝「増分2の時点では呼び出し元が無い（意図的）」`ElementCatalog.cs:18-19`**）。
  **忍者は実機の数値のみ報ずる**——結線の有無の判定は隠密・侍の領分にござる。

**【測れなんだもの】3極記号3種**——**部品選択リスト全24件を末尾まで数えたが、
ブレーカ・電磁接触器主接点・サーマル2極は1件も載っており申さぬ**
（載るのは a接点/b接点/コイル/サーマル/セレクトSW/タイマ4種/モータ/押釦2種/端子台/表示灯/非常停止/
自作7件/OR2種）。**「サーマル」は在るが`サーマル.gcadpart`＝自作パーツ扱いにて、
`ElementKind.ThermalOverload3P`とは別物と見える。**
**Kind経路の配置導線はT-133増分4で新設される予定ゆえ、それを待たねば測れ申さぬ。**
