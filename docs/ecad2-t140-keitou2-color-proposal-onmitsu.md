## 0. 結論（先出し）

**【最も重い所見】両件とも、原本GuiEcadは既に答えを持っておった。しかも二件とも「色を直書きせぬ」形である。**

| | 現状（ecad2） | **原本GuiEcad** | 某の推奨 |
|---|---|---|---|
| **P-150 基準枠** | 灰`180`・破線 | **青`#6096E6`・実線**（`PartEditorWindow.xaml.cs:248`） | **案A＝原本回帰（青の意味色）** |
| **P-158 プレースホルダ** | `Foreground="Gray"` | **色指定なし＋`Opacity=0.6`**（`MainPage.Properties.cs:142-147`） | **案A＝原本回帰（`Opacity`方式）** |

**すなわち「意図的な不在」ではござらぬ**（DoD4）——**原本は両件とも追従する形で作られており、ecad2が移植の際に固定色へ置き換えてしもうた**というのが実相にござる。

**【副次・重い】P-158は「ダークモードの問題」ではござらぬ。ライトモードでも規格を満たしておらぬ。**
**現状`#808080`のコントラスト比＝ダーク`3.47:1`／ライト`3.95:1`——両方とも`4.5:1`を下回り申す。**
**忍者はダークでのみ測られたゆえ、ライト側は誰も測っておらなんだ。**

## 1. DoD4【MUST】原本GuiEcadの確認

### 1.1 P-150＝原本は「灰の中に青を一つ置く」設計

一次ソース＝`C:\Users\kojif\Desktop\生産物\gui_ecad\src\GuiEcad.App\PartEditorWindow.xaml.cs:244-265`

```csharp
private void DrawGrid(CanvasDrawingSession ds)
{
    var faint  = Color.FromArgb( 40, 128, 128, 128);   // 薄い格子
    var line   = Color.FromArgb(120, 128, 128, 128);   // 整数境界
    var frame  = Color.FromArgb(255,  96, 150, 230);   // ★基準範囲の外形枠＝青
    var center = Color.FromArgb(150,  90, 90,  90);    // 行中心線
    ...
    ds.DrawRectangle(..., frame, 1.5f);                // 実線・太さ1.5px

```

**4本の線のうち、枠だけが青**にござる。**残り3本はすべて灰。**
**すなわち原本は「明度」ではなく「色相」で枠を弁別させておる。**

**ecad2の現状はこの構造を失うており申す**——`_theme.Get(StrokeRole.Grid)`由来の灰（区切り線、3段の濃淡）＋
`Fade(_theme.Foreground, 0.55)`の灰（中心線）＋**枠も灰`180`**にて、**4本すべてが灰**。

### 1.2 P-158＝原本は色を指定せず不透明度で弱める

一次ソース＝`MainPage.Properties.cs:140-147`

```csharp
if (_selected is null)
{
    PropertiesPanel.Children.Add(new TextBlock
    {
        Text = "要素を選択してください",
```

**既定の文字色（WinUI3ゆえテーマで切り替わる）に`Opacity`を掛けておる。**
**ecad2の`Foreground="Gray"`は、この方式からの逸脱にござる。**

| **案A（推奨）** | **`DrawingTheme`へ意味色`FrameGuide`を新設**（値＝原本の`(96,150,230)`）。既存の意味色群（`Blue`/`Powered`/`Comment`等、**テーマ非依存**と明記済み）に並べる | **原本回帰。色相で弁別ゆえ灰3本に埋没せぬ。両テーマで4.5:1前後を保つ。「意味色はテーマ非依存」という既存の枠組みにそのまま乗る** | **ライト側の見え方が変わる**（薄灰→青）。新規の色定数が1つ増える |

### 2.3 線種は変えぬことを推す

**原本は実線、ecad2は破線にござる。** されど**本件の題目は「色がテーマに追従せぬこと」**にて、
**線種まで原本へ戻すのは別の話**と某は判ずる。**破線のままで色だけ改めるのを推す。**
（**殿が「原本の見た目へ完全に戻せ」と仰せなら線種も論点になり申すが、それは別途の御裁可を要する。**）

## 5. 推奨のまとめと、殿への論点

**某の推奨＝両件とも案A（原本回帰）にござる。**

**理由が両件で同じである点に、値打ちがあると存ずる**——
**原本は二件とも「固定色を直書きせぬ」形で作られており、ecad2が移植の際に固定色へ置き換えた。**
**すなわち本件は「新しい配色を決める」話ではなく、「原本の設計へ戻す」話にござる。**

**殿にお諮りすべき論点は二つ**

1. **【P-150】ライト側の見え方が変わることを容れられるか**——
   **薄灰の破線が、青の破線になり申す。** **ダーク側だけを直す道（案B）もござるが、
   その場合は灰が4本並び、枠が濃淡の一段に見える恐れがござる**
2. **【P-158＋§4.1の2件】3件まとめて直すか、殿がご指摘の1件のみに絞るか**——
   **同じ意図・同じ対処にて、まとめれば一度で済み申す。**
   **とりわけ§4.3（選択行で読めぬ）は、テーマとは別筋の実害にござる**

**なおP-158は、ライトモードでも規格を満たしておらぬ**（`3.95:1`）。
**「ダークモードの是正」という括りで起票いたしましたが、実は元よりの不備にござった**——
**この一点は、ご裁可の前に必ずお含みおきいただきたく。**
