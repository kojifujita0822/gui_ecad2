# T-145（縦ずれ手当て・案3）再測定 実機確認（忍者）

対象コミット: a7fcb15（VAlign.Middle）／265f677（コメント訂正）。隠密静的レビュー＝方向・仕組み妥当。

操作手法は前ラウンドと同じ（UI Automationで配置・デバイス名入力、画素採取＝PrintWindowスクリーン
ショット＋GetPixel走査、zoom400%）。円中心は上端下端探索または円周上2点からの逆算式、ラベル位置は
バウンディングボックス中心と濃淡重み付き重心の両方で採った。px/mm＝96/25.4×4＝15.118（理論値）。

## 観点1・2 縦ずれの解消、横向き・縦向き両経路

横向きモータ（M1、PartId経路、行4/列5）
円中心(654.5,379.0)。ラベルbbox中心(653,381)、重心(651.39,380.49)。
縦方向dy＝bbox換算+0.132mm（下）、重心換算+0.099mm（下）。
横方向dx＝bbox-0.099mm、重心-0.206mm。

縦向きモータ（M2、Kind経路、行6/列12）
円中心(654.75,379.5)。ラベルbbox中心(655,381)、重心(653.32,381.24)。
縦方向dy＝bbox換算+0.099mm（下）、重心換算+0.115mm（下）。
横方向dx＝bbox+0.017mm、重心-0.095mm。

両経路とも縦方向の残差は約0.10～0.13mmで下方、侍・隠密の申告値（0.0996～0.1284mm）とよく一致する。
前ラウンド（約1.13～1.16mm上方）から一桁縮み、向きも上→下へ反転した。想定内の残差であり、
「まだずれておる」には当たらぬと判ずる。横方向は前ラウンドと同水準（0.02～0.21mm）で変化なし。

## 観点3 既存要素への回帰

コイル（Y1、行10/列5）を最重点として画素採取で測定。
円中心(654.2,379.5)。ラベルbbox中心(652,380)、重心(653.61,378.66)。
縦方向dy＝bbox+0.033mm、重心-0.056mm。横方向dx＝bbox-0.146mm、重心-0.039mm。
いずれも0.1mm未満で、モータの残差（約0.10～0.13mm）や前回のモータの残差（約1.1mm）と比べて
明確に小さく、コイルの意匠（丸の中に名を入れる点でモータと共通）への巻き込みは無いと判ずる。

a接点（X3、行10/列16）は目視で確認。ラベルは記号上部の従来どおりの位置に表示され、丸の中心へ
寄る等の変化は見られなかった（画素測定は行わず、目視のみ）。

## 観点4 絵と名の食い違い

M1・M2とも円の半径はいずれも実測約103.5～104px（理論値6.75mm×15.118px/mm=102.05pxとおおむね
整合、線幅分の差程度）で、横向き・縦向きの間で食い違いは見られなかった。
