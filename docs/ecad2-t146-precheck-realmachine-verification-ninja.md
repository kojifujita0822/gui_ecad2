# T-146 着手前調査 実機確認（忍者）

隠密の静的調査（docs/ecad2-p167-sheet-type-drc-recheck-onmitsu.md）で挙げられた4経路のうち、
実機で確認可能な観点1～3を検分した。操作手法はUI Automation（InvokePattern／SelectionItemPattern）
と物理クリック（Invoke-Ecad2CanvasClick）の併用。

検体＝新規シート2枚（シート1＝主回路、シート2＝制御回路）へ、それぞれコイル無しのa接点（X1／X2）
を1件ずつ配置。ContactWithoutCoil型の警告を確実に踏める最小構成として選んだ。

## 観点1 DRCパネルに診断が実際に出るか

出た。主回路シート（P1）・制御回路シート（P2）とも同一の警告が出た。

重大度=警告 コード=DRC-XREF-001 機器名=X1 該当箇所=P1 行4
メッセージ＝機器 X1: リレー接点がありますが駆動コイルが図面上に見つかりません（駆動元不明）。

重大度=警告 コード=DRC-XREF-001 機器名=X2 該当箇所=P2 行4
メッセージ＝機器 X2: リレー接点がありますが駆動コイルが図面上に見つかりません（駆動元不明）。

文言・コードとも主回路側と制御回路側で完全に同一。静的所見（DRCはDocument.Sheetsを全件ループし
シート種別を見ない）が実機でもそのまま成立することを確認した。

## 観点2 描画時の接続検査（DiagramRenderer.cs:270-271）の見え方

主回路シートには、そもそも母線（N24／P24に相当する縦の帯）自体が描画されない。制御回路シートで
配置したX2は左右の母線を結ぶ横線（母線ライン）に接続された形で表示されるのに対し、主回路シートの
X1は母線ラインを持たず、単独の接点記号のみが表示される（スクリーンショットで確認済み）。

NetlistBuilder.Buildはシート種別を問わず毎回呼ばれる（静的所見のとおり）が、接続診断の可視化
（_opt.ConnectivityCheck）は既定offであり、かつ主回路シート向けのUI操作でこのオプションを
有効化する導線は見当たらなかった。ゆえに本観点は「主回路シートでも制御回路シートと同じ見え方の
差が出るか」という形での比較そのものが成立せず（比較対象となる母線描画が主回路シートに存在しない）、
可視化差分としては確認できなかった。これは観点2の「診断の可視化」ではなく「母線描画の有無」という
別の設計差に起因するものであり、シート種別によるDRC・接続判定のスキップとは別の事実として記録する。

## 観点3 テストモード評価（TestSession.cs）が主回路シートでも走るか

走った。主回路シート（シート1）でテストモード（Ctrl+T）に入り、X1をクリックしたところ、
制御回路シート（シート2）でX2をクリックした場合と同様に接点の表示が反転（背景が水色・接点線が
赤色）した。相違点は、シート2ではさらに母線ライン全体が赤く変化した（母線が主回路シートに存在
しないため、シート1ではこの変化自体が起こりようがない）。

要素そのものの通電状態トグル・評価は主回路シートでも制御回路シートと同じ挙動で走ることを確認した。
静的所見（TestSessionはシート種別を見ない）と一致する。

## 観点4 対照（制御回路シート）

上記のとおり、観点1～3すべてで制御回路シート側の挙動も併記した。制御回路シートは母線描画・
通電時の母線色変化を含めて期待どおりの挙動を示した。

## まとめ

DRCパネル・テストモード評価は主回路シートでも制御回路シートと変わらず動作した（静的所見どおり
「シート種別を見ない」ことを実機で確認）。描画時の接続検査は、主回路シートに母線自体が描画されぬ
という別の設計差のため、可視化差分としての直接比較はできなかった。

範囲外の気づき等は無し。他に診断が鳴る導線は本ラウンドでは見つけていない（隠密の4経路の代表例に
限定して検分した）。
