## 2. 【要確認】一度だけ、バックフィルが働かなんだ——再現せず、原因未特定

**本節は本日の実測で唯一、説明のつかぬものにござる。断定を避けて事実のみ記す。**

### 2-1. 何が起きたか

`sample/t151-ninja-nolib.gcad`（`library=null`、ソレノイドの partId を持つ）を、
**ローカルに `ソレノイド.gcadpart` が在る状態で**引数起動で開き、保存ボタンを押した。

結果＝**保存後も `library` が `null` のまま**であった（機械で確認）。
ファイル自体は更新されておる（`LastWriteTime` が保存操作の時刻、07:43:59）。

### 2-2. 同じ条件で再現を試みたところ、働いた

`sample/t151-nolib2.gcad`（同じ手順で `big_sample.gcad` から生成、中身は同等）を
**同じローカル状態・同じ引数起動・同じ保存手順**で通したところ——

- 開いただけで `IsDirty=true`（バックフィルが働いた証）
- 保存すると `library.byId` にソレノイド1件

すなわち**再現せなんだ**。

### 2-3. 切り分けたこと

| 疑い | 検証 | 結果 |
|---|---|---|
| ローカルのカタログに載っておらぬ | 同一セッションで部品リストを全件走査（25件） | `自作/ソレノイド` は**載っておった**。疑い消える |
| 配置経路も効いておらぬ | 同一セッションで新たに配置し保存 | `library.byId` にソレノイド1件が入った。**配置経路は効いておる** |
| 引数起動が `LoadFromFile` を通らぬ | 同条件を別検体で再試行 | 働いた。**この筋では説明がつかぬ** |

### 2-4. 忍者に言えること・言えぬこと

**言えること**＝上記3つの切り分けの結果と、1回目に `library=null` であった事実。

**言えぬこと**＝原因。以下はいずれも**確かめておらぬ推測**にて、断定として読まれてはならぬ——
検体固有の差（1回目の検体はその前に一度開かれ閉じられておる）／
ローカルへ置いた直後のタイミング（`OneDrive` 配下ゆえ）／忍者の操作の失敗。

**とりわけ最後の筋を排除できておらぬ**——保存ボタンのクリックは合成マウスイベントにて、
押下は効いた（ファイルが更新された）が、**その時点で `Document.Library` が空であった理由**までは
測っておらぬ。

### 2-5. なぜ報ずるか

**再現せぬことをもって「実害なし」とは言えぬゆえにござる。**

もし実際に起こりうるなら、**使い手の図面で移行が黙って行われぬ場合がある**——
しかも `IsDirty` が立たねば保存を促されもせず、**使い手には何も見えぬ**。
次に他所で開いた時に初めて `DRC-PART-001` として現れる筋にござる。

侍・隠密の検分を仰ぎたく存ずる。**一次ソース（`BackfillDocumentLibraryFromLocalCatalog` の
呼び出し位置と条件）を読めば、忍者の実測より早く筋が立つ公算がござる。**

## 4. 操作手法（`ninja.md` 報告フォーマット【MUST】）

- 起動＝`Ecad2.App.exe <パス>` の引数付き直接起動（`Start-Process`）。`dotnet run` を用いず `bin` を汚さぬ形
- DRC＝UIA `ExpandCollapsePattern.Expand()` ＋ `InvokePattern.Invoke()`（**取得失敗時に例外で止まる形へ組んだ**）
- `IsDirty` 判定＝`WindowPattern.Close()` ＋ プロセス生存確認 ＋ `EnumWindows` でダイアログ実在確認
- タブ切替・ボタン押下・部品リスト＝`Invoke-Ecad2ScreenClick`（Win32 `mouse_event` の合成クリック。**殿の実操作にあらず**）
- セル選択＝`Invoke-Ecad2CanvasClick`（同上）。座標は3点較正で確かめた（34px刻み）
- 名前入力＝`Send-Ecad2Keys`
- 撮影＝`Save-Ecad2Screenshot`（PrintWindow）。ダイアログのみ `Ecad2Native.PrintWindow` を直に呼んだ
- 切り出し拡大＝`System.Drawing` で5倍・最近傍補間
- 部品リストの全件走査＝先頭へ戻してから `ScrollVertical(LargeIncrement)` を段階的に（スキル6.1節）
