# リリースノート

ecad2 の各版で加わった機能・変更点です。新しい版が上に来ます。

## v1.0.0（2026-10-09）

最初の正式版です。

### v0.9.6 からの変更点

- **PDF出力の保存先を覚えるようになりました。** 一度PDF出力すると、同じ図面の次回のPDF出力で、保存ダイアログに前回の名前とフォルダが出ます。覚えているのはアプリを開いている間だけで、別の図面を開くと忘れます。
- **リリースノートを追加しました。** ヘルプメニューの「リリースノート」から、この画面を開けます。
- **バージョン情報に著作権表記を追加しました。**

### v1.0.0 時点の主な機能

**図面の作成**

- シートの追加・削除・並べ替え・名前変更。制御回路シートと主回路シートを使い分けられます。
- a接点・b接点・コイル・端子台・押しボタン・表示灯・タイマ接点・セレクトスイッチ・サーマル・非常停止などの配置。主回路シートでは、三相モータ・ブレーカ・電磁接触器の主接点・サーマル（2極）を配置できます。
- OR入力（並列接点）の配置と、合流先を選んでの自動結線。
- 縦分岐線・自由線・接続点・配線分断による結線。
- グループ枠、行コメント、トレース用の下絵画像の挿入。
- 行の追加・挿入・削除。
- 線番の自動採番。

**編集**

- 元に戻す・やり直し。
- 要素・縦分岐線・枠などの、マウスドラッグと矢印キーによる移動。
- 範囲を選んでのコピー・貼り付け。貼り付け位置は確定前に薄く表示され、別のシートへも貼り付けできます。
- 機器番号の挿入（以降を順送り）と、詰め（以降を前へ）。
- 機器名の検索・置換。

**自作パーツ**

- パーツエディタで図形と接続点を描き、自作の部品を作成・編集できます。
- 種別（a接点・b接点・コイル・表示灯・端子台・その他・非シミュレート・外部入力）で、テストモードでの動作と機器表での扱いを決められます。
- パーツを編集して保存すると、開いている図面に配置済みの同じパーツにも反映されます。
- よく使うパーツは「その他図形」メニューへピン留めできます。

**確認と出力**

- 機器表と部品表（BOM）。型式・メーカー・数量・コメントを記入できます。
- 設計チェック（DRC）。結線の不備や、コイルと接点の対応の漏れなどを指摘します。
- テストモード。通電の様子を画面上で確認でき、押しボタンやセレクトスイッチを操作できます。
- PDF出力。プレビューで確認してから出力でき、クロスリファレンス表と部品表が付きます。

**画面**

- ダークモード（作図色）への切り替え。
- ツールバーやパネルの配置変更・フロート表示と、その配置の保存。
- キーボード主体の操作（F5〜F11 での配置、矢印キーでのセル移動、Enter での確定、Esc での取り消し）。

詳しい操作は、ヘルプメニューの「使い方」（F1）をご覧ください。
