## 範囲を選んでコピー・貼り付けする

1. **範囲を選ぶ**: セルを選んでから Shift+矢印キーで広げるか、キャンバス上を左ドラッグします。選ばれた範囲は青く表示されます。選択中の要素の上から始めたドラッグは、従来どおりその要素の移動になります。
2. **コピーする**: Ctrl+C（または編集メニュー・右クリックメニューの「コピー」）。範囲に丸ごと収まる要素・縦分岐線・配線分断・グループ枠が対象です。行コメント・自由線・接続点・画像は対象外です。範囲を選ばずに実行すると、選択中のセルにある要素1つを写します。
3. **貼り付け位置を選ぶ**: Ctrl+V（または「貼り付け」）で、選択中のセルを左上の角として貼り付け後の姿が薄く表示されます。矢印キーかマウスで位置を動かせます。
4. **確定する**: Enter またはクリックで確定、Esc で取りやめです。

貼り付け位置を囲む枠の色は次の意味です。

| 枠の色 | 意味 |
|---|---|
| 青 | そのまま貼り付けます |
| 橙 | 貼り付け先に既に要素などがあるため、コピーした行数ぶんの行を挿入してから貼り付けます |
| 赤 | その位置には貼り付けできません（右へはみ出す、行数の上限を超える、など。理由はステータスバーに表示されます） |

貼り付けた要素の機器名は空になります。コピーした内容は別のシートへも貼り付けできます。貼り付けは「元に戻す」1回で、挿入した行ごと取り消せます。

## 機器番号をまとめて振り直す

番号付きの機器名（CR4、T1 など）を持つ要素を選び、編集メニューまたは右クリックメニューから実行します。

- **機器番号を挿入（以降を順送り）**: CR1〜CR7 があるとき CR4 の要素を選んで実行すると、CR4〜CR7 が CR5〜CR8 になり、CR4 が空きます。新しく置いたコイルに CR4 を付けられます。
- **機器番号を詰める（以降を前へ）**: CR1 を削除したあと CR2 の要素を選んで実行すると、CR2 以降が CR1 以降になります。詰める先の番号がまだ使われている場合は実行されません。

対象は同じ英字部分（CR、T など）を持つ機器名だけで、途中に欠番があっても末尾まで送ります。同じ機器名のコイルと接点は全シートで揃って変わり、機器表の型式やコメントも一緒に移ります。

## ツールバー

ツールバーは「基本機能」と「配置ツール」の2つのタブに分かれています。タブの見出しをクリックして切り替えます。

### 基本機能タブ

新規作成・開く・上書き保存・元に戻す・やり直し・PDF出力・行を追加(Ctrl+Shift+↑)・行を削除(Ctrl+Shift+↓)・テストモード切替のボタンがあります。

### 配置ツールタブ

選択ツール(Esc)・a接点(F5)・OR a接点(Shift+F5)・b接点(F6)・OR b接点(Shift+F6)・コイル(F7)・端子台(F8)・自由線横(F9)・自由線縦(Shift+F9)・縦分岐線(Shift+F9)・接続点(F10)・配線分断(F10)・グループ枠・自作パーツ(F11)の各ボタンがあります。

Shift+F9・F10は、開いているシートが主回路か制御回路かによって実行される操作が変わります（シート/ドキュメント管理の項目を参照）。

## 今どのツールを使っているか一目でわかる

配置ツールタブのボタンは、現在選択中のツールが背景色と枠線で常時ハイライト表示されます。マウスカーソルを離してもハイライトは維持されるので、今どの操作モードにいるか一目で分かります（接続点記入・配線分断記入は、押した瞬間に処理が完了する操作のため対象外です）。

ボタンを押した瞬間には、これとは別に一時的な押下フィードバック（色の変化）も表示されます。

無効な状態のボタンは薄く表示されます（例：プロジェクトが無い状態での配置系ボタン）。

## パネルの配置は自由に変更できる

ツールバー・左側のパレット・右側のパネル・下部の出力パネルは、いずれもドラッグでの移動・フロート表示（ウィンドウとして独立させる）が可能です。配置を変更した後、「表示」メニューの「現在のレイアウトを既定として保存」を実行すると、次回起動時も同じ配置が復元されます。
