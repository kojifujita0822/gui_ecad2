# 部品選択・自作パーツ管理

要素を配置する際に使う部品選択パネルと、自作パーツの追加方法を説明します。

## 部品選択パネル

ツールバーの「自作パーツ」ボタン（F11）を押すと、右側のパネルが部品選択リストに切り替わります。あらかじめ用意された部品（a接点・b接点・コイル・端子台・セレクトスイッチ・押釦・ランプ・モーター・タイマ接点・サーマルリレー・非常停止ボタンなど）と、自分で追加した自作パーツが、区別なく同じ一覧に表示されます。

一覧の各項目にはサムネイル画像・カテゴリ名・部品名が表示されます。クリックするとキャンバス上に配置できます（配置操作の項目を参照）。

## 自作パーツを作る

「パーツ」メニューの「新規作成...」で、自作パーツのエディタが開きます。図面の編集ができる状態でのみ選べます。

![自作パーツのエディタ](images/part-editor.png)

1. **名前**: パーツの名前を入力します。
2. **役割**: パーツの種類（a接点、コイルなど）を選びます。
3. **配置先**: 配置できる回路の種類を選びます。
4. **図形ツール**: 線・折れ線・矩形・円・弧・文字で記号の形を描き、接続点を置きます。使い方は下の「図形ツールの使い方」を参照してください。
5. **OK**: 保存すると、部品選択パネルの一覧に加わります。

幅・高さ（セル単位、1〜12）でパーツの大きさを決めます。Ctrl+ホイールで拡大縮小、中ボタンのドラッグで表示位置を動かせます。

### 図形ツールの使い方

ツールバーのボタンでツールを切り替え、キャンバス（格子の描かれた領域）の上で操作します。

| ツール | 操作 |
|---|---|
| 選択 | 図形をクリックして選び、ドラッグで動かします。選んだ図形は「選択を削除」ボタンか Delete キーで消せます。接続点も同じ方法で選んで動かせます（重なっているときは接続点が優先されます）。 |
| 線 | 始点でマウスのボタンを押し、終点まで動かして離します。 |
| 折れ線 | 曲がる点を順にクリックしていき、右クリックで確定します。点が2つ未満のときは何も描かれません。 |
| 矩形 | 対角の2点を、ドラッグで指定します。 |
| 円 | 中心でボタンを押し、円周上の1点まで動かして離します。中心から離した点までの距離が半径になります。 |
| 弧 | 外側の枠の対角2点を、ドラッグで指定します。この枠に収まる半円の弧が描かれます。 |
| 回転 | 回したい図形の上でボタンを押し、ドラッグします。図形の中心を軸に、15度刻みで回ります。 |
| 文字 | 置きたい位置をクリックすると入力欄が開きます。入力した文字がその位置に置かれます。 |
| 接続点 | 下の「接続点を置く」を参照してください。 |

- 線・矩形・円・弧は、ドラッグの途中で Esc を押すと取りやめられます。長さや大きさがゼロのまま離した図形は、描かれません。
- 「スナップ」ボタンを押している間は、点が格子の4分の1の刻みに合わせられます。初期状態ではオフで、自由な位置に描けます。
- 「元に戻す」「やり直し」は、ボタンのほか Ctrl+Z と Ctrl+Y でも使えます。
- 表示の拡大縮小は Ctrl+ホイールです。中ボタンのドラッグで表示位置を動かせ、「ズームを戻す」で元の倍率に戻ります。

### 接続点を置く

接続点は、パーツを図面に置いたときに配線がつながる点です。図形ツールの「接続点」を選び、キャンバスをクリックして置きます。

- 位置は格子の交点に自動で合わせられます。左右はパーツの左端から右端まで、上下は中心の行を基準に、高さより1つ少ない行数まで置けます。
- すでに接続点がある位置には、重ねて置けません。置いた順に P1、P2 と名前が付きます。
- 置いた後は「選択」ツールに切り替えて、接続点をクリックして選びます。ドラッグで動かし、Delete キーで削除できます。
- 接続点を選ぶと、種類の欄が現れます。「電源に接続される点（赤）」と「DRC無効な点（青）」から選べ、点の色が変わります。現時点では色の区別だけで、設計チェックの結果には影響しません。

保存するときは、次の条件が確かめられます。条件を満たさないと保存できず、理由がエディタに表示されます。

- 接続点が2つ以上あること（シミュレーションの対象外にする役割を除く）。
- 基準枠に収めたとき、接続点が重ならないこと。枠の外に置いた接続点は、保存時に枠の内側へ寄せられます。
- すべての接続点が同じ左右位置にならないこと。左右に分けて置いてください。

保存時には、接続点は左から右の順に並べ替えられます。

作ったパーツは `.gcadpart` ファイルとして自作パーツの保存フォルダに保存されます。ファイルを直接以下のフォルダへ置いても使えます。

```
マイドキュメント\Ecad2\図形\自作\
```

作ったパーツの編集と削除は、「パーツ」メニューの「自作パーツ」から行えます。

直接置いたファイルは、次回パネルを開いたときに自動的に一覧へ反映されます。

同じ部品ファイルをコピーするなどしてID（内部識別子）が重複した場合は、アプリが自動的に別のIDへ割り当て直すため、通常は問題になりません。
